Extensions

Extension Management

PJSIP accounts — written to PostgreSQL, read by Asterisk via ODBC realtime.

New extensions include call routing automatically. Use the extension number as both the SIP account and authentication username. Optionally create voicemail for unanswered, busy or unavailable phones. Edit existing routing on the Dialplan page and mailbox settings on the Voicemail page. Deletion retains routing/mailboxes and does not terminate calls.
